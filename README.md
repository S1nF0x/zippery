# zippery

A modern and customizable file manager with a clean GUI, built in Rust.

## Features

- 📂 File browsing and renaming

- 🖼️ Custom background support

- 📦 Future plan for archive compression and extraction
## Roadmap

This project is still in active development:

- [ ] Core file compression support
- [ ] File extraction system
- [ ] Drag and drop support
- [ ] UI customization improvements
- [ ] Performance optimizations

## Usage
```bash
git clone https://github.com/S1nF0x/zippery.git
cd zippery
cargo build --release
```
